# Hunter3DVisual Workspace

## Project
AI-powered OS for Archviz studio.

## Stack
Next.js 14, TypeScript, TailwindCSS, shadcn/ui, Supabase, Prisma, Clerk, Framer Motion

## Design
Dark mode, cinematic UI, minimal, futuristic, modular

## Modules
Projects, Clients CRM, Production Pipeline, Finance, Quotes & Invoices, 
Asset Library, Tasks, Team Workspace, AI Assistant, Automation

## Conventions
- Components: src/components/<module>/
- Pages: src/app/(dashboard)/<module>/
- Types: src/types/<module>.ts
- Hooks: src/hooks/use-<name>.ts
- Server actions: src/actions/<module>.ts

## Rules
- No comments in code unless critical
- No mock data unless asked
- No explanations, just code
- One module per session
